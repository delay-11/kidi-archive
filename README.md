# KIDI ARCHIVE

키보드·스위치·키캡이 처음이라 용어부터 막막한 분들을 위한 참고용 웹사이트예요.
배열, 스위치, 프로파일 같은 기본 개념 정리부터 나에게 맞는 조합 찾기, 키캡 호환 여부 확인까지 한 곳에서 볼 수 있어요.

🔗 **사이트 바로가기**: https://archive.keycapdesign.co.kr

---

## 주요 기능

- **카테고리별 정보** — 키보드 종류·배열, 스위치 타입·축 종류, 키캡 프로파일, 커스텀 방식, 용품
- **나에게 맞는 조합 찾기** — 간단한 질문에 답하면 어울리는 배열·스위치·프로파일 조합을 추천
- **호환 가능 여부 확인하기** — 제품명 검색 또는 브랜드별 보기로 키캡 호환 여부 확인
- **스위치 타건음 미리듣기 / 스펙 보기**
- **모델 등록 요청** — 목록에 없는 제품은 톡톡으로 바로 등록 요청 가능
